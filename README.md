# DentalTouch — Patient Pre-Examination

> 환자 친화형 스마트 치과 예진 웹 프로토타입

- **개발 기간:** 2026.09.04 ~ 2026.09.20
- **프로젝트:** Wanted AI Championship 2026 / 5인 팀
- **주요 기술:** React, TypeScript, Firebase Firestore

## 프로젝트 소개

고령 환자의 디지털 문진 접근성을 고려하여, 환자가 단계별로 증상과 진료 관련 정보를 입력할 수 있도록 만든 스마트 예진 시스템입니다. 의료진이 진료 전에 환자의 주요 정보를 확인할 수 있도록 하는 것을 목표로 했습니다.

## 주요 기능

- 단계별 환자 기본정보 및 증상 입력
- 치아·구강 이미지 기반 통증 부위 선택
- 통증 강도, 과거 병력, 복용 약물, 알레르기 등 예진 항목 입력
- 예진 결과를 의료진용 화면에서 활용할 수 있도록 정보 연계

## 담당 역할

- 환자 예진 과정과 화면 흐름 기획
- 의료 도메인 팀원의 요구사항을 기능 단위로 정리
- AI 코딩 도구를 활용한 예진 웹 프로토타입 개발 전담
- 화면 동작 테스트 및 피드백 기반 수정
- Firestore 연동 과정에서 발생한 일부 오류 해결

## 구현 방식에 대한 설명

AI 코딩 도구를 이용해 요구사항을 구체화하고 생성된 코드를 실행·테스트하는 방식으로 개발했습니다. 현재 확인된 코드 분석에서는 정규식·키워드 처리 및 사전 정의된 임상 프로필이 사용된 것으로 보고되었으며, **Gemini Structured Output API가 서비스 실행 중 호출된다고 확인되지는 않았습니다.**

따라서 이 프로젝트를 실시간 생성형 AI 문진 분석 서비스로 소개하지 않습니다.

## 테스트 데이터

실제 환자 정보를 사용하지 않았습니다. 시연 및 기능 테스트에는 생성형 AI로 만든 가상 환자 데이터가 사용되었습니다. 이 데이터는 임상적으로 검증된 데이터가 아닙니다.
